Prompt untuk AI Coding Tool: Aplikasi Kamera Sekali Pakai Digital untuk Pernikahan Salin seluruh teks di bawah ini dan masukkan ke Open Code (atau Claude Code / Cursor / tool AI coding lainnya). PROMPT Saya ingin membuat web app "kamera sekali pakai digital" untuk acara pernikahan saya (bukan produk komersial, hanya untuk 1 acara dengan sekitar 150200 tamu). Tolong bangun aplikasi ini dari awal dengan spesifikasi berikut: Konsep Tamu undangan scan QR code atau buka link → langsung bisa ambil foto lewat browser HP mereka (tanpa install app apapun) → foto otomatis tersimpan ke galeri bersama → semua foto baru bisa dilihat semua orang setelah acara selesai ("reveal"bersamaan), seperti kamera film analog yang baru bisa dilihat setelah dicetak. Tech Stack yang Diinginkan Frontend : Next.js (App Router) + Tailwind CSS Backend & Database : Supabase (gunakan free tier: Postgres + Storage + Realtime) Hosting : harus bisa di-deploy gratis ke Vercel Tanpa sistem login/akun tamu — akses cukup lewat link/QR unik (token di URL) PWA-ready agar terasa seperti aplikasi native saat dibuka di HP tamu Fitur Wajib 1. Halaman Kamera (untuk tamu) Akses kamera HP lewat browser (getUserMedia API), harus kompatibel dengan iOS Safari dan Android Chrome Tombol jepret foto (shutter), preview sebelum upload opsional Terapkan filter warna vintage/film look (grain halus, warna hangat/pudar) menggunakan CSS filter atau Canvas Batasi jumlah foto per tamu, contoh: maksimal 15-20 foto per device/token(simpan hitungan di local storage device + validasi di server) Upload otomatis ke Supabase Storage setelah difoto, dengan kompresi gambar di sisi klien sebelum upload (resize ke maks. 1600px, kualitas JPEG 70-80%) agar hemat bandwidth di venue dengan koneksi lambat Tampilkan indikator "foto tersimpan" tapi JANGAN tampilkan hasil foto ke tamu (biar surprise saat reveal) Opsional: fitur rekam pesan suara singkat (maks 30 detik) yang tersimpan bareng sesi tamu tersebut 2. Sistem Reveal Semua foto disembunyikan dari semua orang (termasuk saya sebagai host) sampai waktu/tanggal tertentu yang saya set di awal Setelah waktu reveal tercapai, semua foto otomatis terbuka untuk dilihat semua orang yang punya link galeri Simpan waktu reveal di database, cek otomatis di frontend (bukan manual trigger) 3. Halaman Galeri (setelah reveal) Grid foto semua tamu, bisa di-scroll Bisa download foto satu per satu (tombol download per foto)Opsional: tombol "download semua" (zip semua foto) Tidak perlu login untuk lihat galeri — cukup akses lewat link acara 4. Halaman Admin/Host (untuk saya) Buat 1 acara (nama acara, tanggal pernikahan, waktu reveal) Generate QR code otomatis dari link kamera acara tersebut (bisa didownload sebagai gambar untuk dicetak/ditaruh di meja tamu) Lihat jumlah foto yang sudah masuk secara real-time Tombol untuk override/percepat waktu reveal secara manual (jaga-jaga) Yang TIDAK Perlu Dibuat Sistem pembayaran (payment gateway) — aplikasi ini untuk 1 acara pribadi, bukan produk berbayar Multi-tenant / multi-event / multi-user host Sistem akun & login untuk tamu Struktur Data yang Disarankan (Supabase) Tabel event : id, nama_acara, tanggal_acara, waktu_reveal, link_token Tabel photos : id, event_id, url_foto, guest_session_id, created_atTabel voice_notes (opsional): id, event_id, url_audio, guest_session_id, created_at Supabase Storage bucket terpisah untuk foto dan audio Prioritas Pengerjaan Tolong bangun secara bertahap dan jelaskan tiap langkah karena saya tidak punya latar belakang coding sama sekali: 1. Setup project Next.js + koneksi ke Supabase (jelaskan cara saya bikin akun Supabase gratis dan ambil API key) 2. Halaman kamera dasar (ambil & upload foto, tanpa filter dulu) 3. Sistem batas foto per tamu + kompresi gambar 4. Filter vintage 5. Sistem reveal berbasis waktu 6. Halaman galeri 7. Halaman admin + generate QR code 8. Testing di HP asli (bukan cuma browser desktop) sebelum hari-H, terutama di iPhone/Safari karena paling sering bermasalah dengan akses kamera Catatan Penting Saya tidak bisa coding sama sekali, jadi setiap instruksi setup (buat akun, copy-pasteenvironment variable, cara deploy ke Vercel) harus dijelaskan selangkah demi selangkah seperti untuk pemula total. Prioritaskan stabilitas dan kesederhanaan dibanding fitur tambahan — ini dipakai sekali di hari pernikahan saya dan tidak boleh gagal.
